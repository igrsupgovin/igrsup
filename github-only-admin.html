GitHub-only रिकॉर्ड प्रबंधन

रिकॉर्ड सीधे आपके GitHub repository की records.json फाइल में सेव होंगे।
महत्वपूर्ण गोपनीयता सूचना: यह GitHub-only तरीका है, लेकिन repository Public है। records.json में मौजूद सभी रिकॉर्ड कोई भी व्यक्ति डाउनलोड और पढ़ सकता है—केवल ID वाला व्यक्ति नहीं। पुराने commits में हटाए गए रिकॉर्ड भी रह सकते हैं। केवल वही जानकारी रखें जिसे सार्वजनिक करना अधिकृत हो। यह सरकारी पोर्टल नहीं है।

GitHub access token

GitHub पर Fine-grained personal access token बनाएँ। केवल इसी repository को चुनें और Repository permissions में Contents = Read and write दें। Token को किसी HTML/JS फाइल या chat में न डालें। इस पेज में token केवल खुले हुए tab की memory में रहेगा; Refresh/Close करने पर फिर डालना होगा।
